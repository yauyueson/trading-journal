## 🎯 DTE5 Bull Put 专属工作流

> 当前唯一活跃策略。Swing 和 ShortTerm 策略已退役（代码保留仅为兼容历史数据库数据）。

### 策略参数

| 参数 | 值 |
|------|------|
| 标的 | QQQ（仅此一只） |
| 方向 | Bull Put Credit Spread |
| Short Leg Delta | 0.30 |
| Long Leg Delta | 0.20 |
| Spread Width | $10 |
| DTE | 2-7 天 |
| 入场条件 | EMA34 看涨（价格 > EMA34） |
| 出场策略 | 持有至到期（hold-to-expiry） |
| 止损 | Delta Stop（回测引擎内置） |
| 持仓限制 | 最多 1 个持仓，每个 Ticker 最多 1 个 |
| 账户规模 | $10K（Paper Trading） |
| 单笔风险 | 账户的 10% |
| 利润目标 | 100%（即全额收取权利金） |

### 每日工作流

```
1. 打开 Dashboard → 查看当日信号状态
   ↓
2. 前往 Signals 页面 → 检查 QQQ 是否出现 EMA34 看涨信号
   ↓
3. 若 QQQ 看涨 → 前往 Strategy Recommender（/selector）
   ↓
4. 输入 Ticker: QQQ, Direction: BULL
   ↓
5. 系统推荐 DTE5 Bull Put Spread（delta 0.30 short / 0.20 long, $10 宽度, DTE 2-7）
   ↓
6. 确认无现有持仓（最多 1 个）→ 开仓
   ↓
7. 持有至到期，无需主动管理
```

## 🔍 Strategy Recommender 使用指南

> 路由: `/selector`

### 基本使用

**1. 确认入场信号**
- 在 Signals 页面确认 QQQ 出现 EMA34 看涨信号（价格 > EMA34）
- DTE5 策略不使用 Score Tier 或 Pine Script 信号

**2. 输入参数至 Strategy Recommender**
- **Ticker**: 股票代码（当前仅交易 QQQ）
- **Direction**: BULL（DTE5 策略固定为看涨方向）
- **Target DTE**: 目标到期天数（DTE5 为 2-7 天）
- 系统会根据策略配置自动推荐合适的期权结构

**3. 获取分析结果**
- Strategy Recommender 根据输入推荐 DTE5 Bull Put Credit Spread
- Short leg: delta 0.30
- Long leg: delta 0.20
- Spread width: $10
- 系统自动评分并排序推荐策略

**4. 查看结果**
- 查看推荐策略的评分和参数
- 绿色 = 80+分（优秀）
- 蓝色 = 70-79分（良好）
- 灰色 = 60-69分（一般）
- 红色 = <60分（不建议）

---

### 评分解读

**LOQ Score (买方)**

**80-100分 - 优秀机会**
- ✅ 高杠杆（Lambda 5-15）
- ✅ 高爆发力（Gamma Eff 0.01-0.05）
- ✅ 低时间衰减（Theta Burn <0.02）
- ✅ ATM区间（Delta 0.30-0.50）
- ✅ IV便宜（Contango）

**示例**: QQQ $630 Call, 45 DTE, Delta 0.45, Score 85
- 理想的swing trade机会
- 适合持有1-3周

**70-79分 - 良好机会**
- ✅ 大部分指标优秀
- ⚠️ 某些指标略差（如IV偏贵）

**示例**: SPY $580 Put, 30 DTE, Delta 0.35, Score 72
- 可以考虑，但需谨慎
- 适合短期交易（1周内）

**60-69分 - 一般机会**
- ⚠️ 多个指标不理想
- 🚫 不建议新手交易

**<60分 - 不建议**
- 🚫 彩票式期权（Delta <0.15）
- 🚫 IV过贵（Backwardation）
- 🚫 时间衰减过快

---

### IV Term Structure解读

**Contango (IV Ratio < 0.95)**
- ✅ **适合买入**
- 近期IV低，远期IV高
- 期权相对便宜

**Neutral (IV Ratio 0.95-1.05)**
- ⚠️ **谨慎买入**
- IV正常水平
- 需要其他指标支持

**Backwardation (IV Ratio > 1.05)**
- 🚫 **不建议买入**
- ✅ **适合卖出**
- 近期IV高，市场恐慌
- 期权过贵

## 📝 Watchlist管理

> Watchlist 是 Portfolio 页面中的一个状态（tab），不是独立页面。

### 添加到Watchlist

**方法1: 从Strategy Recommender添加**
```
Strategy Recommender（/selector）→ 找到推荐策略 → "Add to Watchlist"
```

**方法2: 手动添加**
```
Portfolio 页面 → Watchlist tab → "+" 按钮 → 填写信息
```

### 必填信息

| 字段 | 说明 | 示例 |
|------|------|------|
| Ticker | 股票代码 | QQQ |
| Strike | 行权价 | 530 |
| Type | Put Credit Spread | Credit Put Spread |
| Expiration | 到期日 | 2026-04-11 |
| **Setup** | **自由文本备注** | **EMA34 bullish** |
| **Strategy** | **期权结构类型** | **Credit Put Spread** |
| Ideal Entry | 理想入场价（收取权利金） | 0.45 |
| Stop Reason | 止损条件 | Delta stop |

### 监控Watchlist

**每日检查**:
1. 当前价格 vs 理想入场价
2. EMA34 信号是否仍然看涨
3. 是否有合适的 DTE 2-7 天到期合约

**入场时机**:
- ✅ QQQ EMA34 看涨（价格 > EMA34）
- ✅ DTE 在 2-7 天范围内
- ✅ 当前无活跃 DTE5 持仓

**移除条件**:
- ❌ EMA34 转为看跌
- ❌ 已有活跃 DTE5 持仓
- ❌ 市场条件不适合

## 📋 Paper Trading 工作流

> 当前 DTE5 策略在 Paper Trading 模式下运行（$10K 账户）。

### Paper/Live 切换

```
Portfolio 页面 → 顶部 PAPER/LIVE 切换按钮
```
- 点击切换可在 Paper 和 Live 模式之间切换
- Paper 和 Live 持仓共存于同一数据库
- 切换仅影响显示过滤，不影响数据

### Paper 持仓标识

- Paper 持仓在卡片上显示 **PAPER** 徽章
- 可点击 PAPER/LIVE 标签切换单个持仓的模式
- 位置数据中通过 `is_paper` 布尔值区分

### P&L 追踪

- Paper 和 Live 持仓的 P&L 分别追踪
- Stats 页面可按 Paper/Live 过滤统计数据
- 方便在 Paper 模式下验证策略后再切换到 Live

### 建议工作流

```
1. 使用 Paper Trading 验证 DTE5 策略（当前阶段）
   ↓
2. 积累足够样本量后评估绩效
   ↓
3. 确认策略有效后切换到 Live 模式
   ↓
4. Live 模式下使用相同的风险参数
```

## 🛡️ 风险管理

### DTE5 风险规则

**止损**
- Delta Stop：回测引擎内置的 delta-based 止损
- 无百分比止损（持有至到期）
- 无时间止损（DTE5 本身就是短期策略，2-7 天到期）

**持仓限制（DTE5）**

| 参数 | 值 |
|------|------|
| 最大持仓数 | 1 |
| 每个 Ticker 最大持仓 | 1 |
| 标的限制 | QQQ only |
| 利润目标 | 100%（全额收取权利金，持有至到期） |

---

### 仓位管理（DTE5）

**风险计算方式**:
- 使用 **stop-out level**（非最大亏损）作为风险基准
- 0.25 Kelly fraction
- `getPositionRiskAtStopOutDollars()` 计算单笔风险
- 单笔风险上限: `maxRiskPerTrade`（AppSettings 配置）

**账户参数**:
- 账户规模: $10K（Paper Trading）
- 单笔风险: 账户的 10%（即 $1,000）
- 最大持仓: 1 个

**注意**: DTE5 策略不支持加仓。每次只能持有 1 个 DTE5 持仓，到期后方可开新仓。

## ✅ 最佳实践

### 入场纪律

**EMA34 门控（DTE5）**
- ✅ 只在 QQQ 价格 > EMA34 时入场
- ✅ Signals 页面确认 EMA34 看涨信号
- ❌ 不要在 EMA34 看跌时逆势做多

**DTE 检查**
- ✅ 到期日在 2-7 天范围内
- ❌ 不要交易 DTE > 7 或 DTE < 2 的合约

**持仓检查**
- ✅ 确认当前无活跃 DTE5 持仓
- ❌ 不要同时持有多个 DTE5 持仓

---

### 出场纪律（DTE5）

**默认策略: 持有至到期**
- DTE5 策略的利润目标是 100%（全额收取权利金）
- 不需要主动止盈或时间止损
- 到期时如果 QQQ 价格 > short put strike，全额获利

**Delta Stop**
- 回测引擎内置的 delta-based 止损
- 当持仓 delta 超过阈值时触发
- 由系统自动管理

### 常见错误

**❌ 错误1: 忽略 EMA34 信号**
- EMA34 看跌时仍然做多
- 不检查 Signals 页面就开仓

**✅ 正确做法**:
- 严格遵守 EMA34 门控
- 每次开仓前在 Signals 页面确认信号

**❌ 错误2: 过度交易**
- 到期当天立刻开新仓
- 同时持有多个 DTE5 持仓

**✅ 正确做法**:
- DTE5 最多 1 个持仓
- 等待明确的 EMA34 信号再入场

**❌ 错误3: 提前平仓**
- 获利 50% 就急于止盈
- 恐慌性平仓

**✅ 正确做法**:
- DTE5 策略设计为持有至到期
- 利润目标是 100%（全额收取权利金）
- 信任 delta stop 作为风控机制

**❌ 错误4: 交易非 QQQ 标的**
- 将 DTE5 策略应用于其他 Ticker

**✅ 正确做法**:
- DTE5 当前仅验证于 QQQ
- 其他标的未经回测验证，不应交易

## 🎯 交易案例

### 案例1: DTE5 Bull Put 全额获利

**策略**: QQQ Bull Put Credit Spread (DTE5)

**流程**:
```
Day 0: Signals 页面确认 QQQ EMA34 看涨
       → Strategy Recommender 推荐 DTE5 Bull Put
       → 卖出 QQQ $525/$515 Put Spread (DTE 5)
       → 收取权利金 $0.45/份

Day 5: QQQ 收盘价 $532（高于 short put $525）

       → 全额获利 $0.45/份

```

**关键点**:
- ✅ EMA34 信号确认后入场

### 案例2: DTE5 Bull Put 止损触发

**策略**: QQQ Bull Put Credit Spread (DTE5)

**流程**:
```
Day 0: Signals 页面确认 QQQ EMA34 看涨
       → 卖出 QQQ $530/$520 Put Spread (DTE 4)
       → 收取权利金 $0.50/份

       → 提前平仓，亏损 $3.50/份
```

- ✅ 单笔风险控制在账户 10% 以内
- ✅ 亏损后等待下一个 EMA34 信号再入场
