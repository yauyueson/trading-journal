## 📊 表结构设计

### 1. positions (持仓表)

**用途**: 存储所有期权持仓（观察列表、活跃持仓、历史持仓）

**Schema**:
```sql
CREATE TABLE positions (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 期权基本信息
    ticker VARCHAR(20) NOT NULL,           -- 股票代码 e.g. "QQQ"
    strike DECIMAL(10,2) NOT NULL,         -- 行权价 e.g. 630.00（价差时=锚定腿）
    type VARCHAR(50) NOT NULL,             -- "Call"/"Put" 或 "Credit Put Spread" 等
    expiration DATE NOT NULL,              -- 到期日 e.g. 2026-02-20

    -- 状态管理
    status VARCHAR(20) NOT NULL DEFAULT 'watchlist',
        -- 'watchlist': 观察列表
        -- 'active': 活跃持仓
        -- 'closed': 已平仓

    -- 交易计划
    setup VARCHAR(50),                     -- 交易设置类型 e.g. "MB Bounce"
    entry_score INTEGER,                   -- 入场时Scanner Score (0-100)
    current_score INTEGER,                 -- 当前Scanner Score (0-100)
    score_updated_at TIMESTAMPTZ,          -- Score最后更新时间
    ideal_entry DECIMAL(10,2),             -- 理想入场价 e.g. 7.50

    -- 价格和风控
    current_price DECIMAL(10,2),           -- 当前期权价格
    stop_reason TEXT,                      -- 技术止损条件 e.g. "MB flips red"
    target_price DECIMAL(10,2),            -- 目标价 e.g. 12.00
    stop_price DECIMAL(10,2),             -- 手动止损价（如设置则覆盖计算值）

    -- 价差（Spread）支持
    legs JSONB,                           -- 价差腿 [{strike, type, side, expiration}, ...]

    -- 多账户支持
    owner VARCHAR(20) DEFAULT NULL,       -- 持仓归属人 'Yuchen' / 'Annie' / NULL

    -- 备注和时间戳
    notes TEXT,                            -- 交易笔记
    created_at TIMESTAMPTZ DEFAULT NOW(),  -- 创建时间
    closed_at TIMESTAMPTZ,                 -- 平仓时间

    -- 约束
    CHECK (status IN ('watchlist', 'active', 'closed')),
    CHECK (strike > 0),
    CHECK (entry_score IS NULL OR (entry_score >= 0 AND entry_score <= 100)),
    CHECK (current_score IS NULL OR (current_score >= 0 AND current_score <= 100))
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| ticker | VARCHAR(20) | ✅ | 股票代码，大写 |
| strike | DECIMAL(10,2) | ✅ | 行权价，精确到分 |
| type | VARCHAR(50) | ✅ | Call/Put 或价差类型如 "Credit Put Spread" |
| expiration | DATE | ✅ | 到期日 |
| status | VARCHAR(20) | ✅ | 持仓状态 |
| setup | VARCHAR(50) | ❌ | 交易设置类型 |
| entry_score | INTEGER | ❌ | 入场评分 |
| current_score | INTEGER | ❌ | 当前评分 |
| score_updated_at | TIMESTAMPTZ | ❌ | 评分更新时间 |
| ideal_entry | DECIMAL(10,2) | ❌ | 理想入场价 |
| current_price | DECIMAL(10,2) | ❌ | 当前价格 |
| stop_reason | TEXT | ❌ | 止损条件 |
| target_price | DECIMAL(10,2) | ❌ | 目标价 |
| stop_price | DECIMAL(10,2) | ❌ | 手动止损价 |
| legs | JSONB | ❌ | 价差腿 [{strike, type, side, expiration}] |
| owner | VARCHAR(20) | ❌ | 持仓归属人（Yuchen/Annie） |
| strategy | VARCHAR(50) | ❌ | 期权结构类型（如 "Credit Put Spread"） |
| exit_type | VARCHAR(20) | ❌ | 平仓原因（stop_loss/take_profit/expired/manual） |
| tech_score | INTEGER | ❌ | 技术面评分 (0-100) |
| tech_score_source | VARCHAR(20) | ❌ | 评分来源（auto/manual） |
| market_state | VARCHAR(20) | ❌ | 入场时市场状态 |
| trade_profile | VARCHAR(20) | ❌ | 交易风格（day_trade/swing/position） |
| iv_rank_entry | DECIMAL(5,2) | ❌ | 入场时 IV Rank |
| iv_regime_entry | VARCHAR(20) | ❌ | 入场时 IV Regime（contango/backwardation） |
| notes | TEXT | ❌ | 备注 |
| created_at | TIMESTAMPTZ | ✅ | 创建时间（自动） |
| closed_at | TIMESTAMPTZ | ❌ | 平仓时间 |

**示例数据**:
```sql
INSERT INTO positions (ticker, strike, type, expiration, status, setup, entry_score, ideal_entry, stop_reason)
VALUES 
  ('QQQ', 630.00, 'Call', '2026-02-20', 'watchlist', 'MB Bounce', 85, 7.50, 'MB flips red'),
  ('SPY', 580.00, 'Put', '2026-03-15', 'active', 'Breakdown', 72, 5.20, 'Breaks above 585');
```

### 2. transactions (交易记录表)

**用途**: 记录所有买入/卖出操作

**Schema**:
```sql
CREATE TABLE transactions (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 外键关联
    position_id UUID REFERENCES positions(id) ON DELETE CASCADE,
    
    -- 交易信息
    type VARCHAR(20) NOT NULL,             -- 交易类型
        -- 'Open': 开仓
        -- 'Size Up': 加仓
        -- 'Size Down': 减仓
        -- 'Take Profit': 部分止盈
        -- 'Close': 平仓
    
    quantity INTEGER NOT NULL,             -- 数量（正=买入，负=卖出）
    price DECIMAL(10,2) NOT NULL,          -- 成交价
    date TIMESTAMPTZ DEFAULT NOW(),        -- 交易时间
    note TEXT,                             -- 交易备注
    
    -- 约束
    CHECK (type IN ('Open', 'Size Up', 'Size Down', 'Take Profit', 'Close')),
    CHECK (quantity != 0),
    CHECK (price > 0)
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| position_id | UUID | ✅ | 关联的持仓ID |
| type | VARCHAR(20) | ✅ | 交易类型 |
| quantity | INTEGER | ✅ | 合约数量 |
| price | DECIMAL(10,2) | ✅ | 成交价格 |
| date | TIMESTAMPTZ | ✅ | 交易时间（自动） |
| note | TEXT | ❌ | 交易备注 |

**数量规则**:
- **正数**: 买入操作
  - `Open`: +5 (开仓5份)
  - `Size Up`: +3 (加仓3份)
- **负数**: 卖出操作
  - `Size Down`: -2 (减仓2份)
  - `Take Profit`: -3 (止盈3份)
  - `Close`: -5 (平仓5份)

**示例数据**:
```sql
-- 开仓5份 @ $7.50
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Open', 5, 7.50, 'Entry at ideal price');

-- 加仓3份 @ $6.80
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Size Up', 3, 6.80, 'Dip buy');

-- 止盈4份 @ $10.20
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Take Profit', -4, 10.20, 'Hit target');

-- 平仓剩余4份 @ $9.50
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Close', -4, 9.50, 'Close remaining');
```

### 3. position_greeks_history (Greeks历史表)

**用途**: 存储IV和Delta的历史快照，用于图表展示

**Schema**:
```sql
CREATE TABLE position_greeks_history (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 外键关联
    position_id UUID REFERENCES positions(id) ON DELETE CASCADE,
    
    -- Greeks数据
    iv DECIMAL(6,4) NOT NULL,              -- 隐含波动率 e.g. 0.1778
    delta DECIMAL(6,4) NOT NULL,           -- Delta值 e.g. 0.3999
    
    -- 时间戳
    recorded_at TIMESTAMPTZ DEFAULT NOW(), -- 记录时间
    
    -- 约束
    CHECK (iv >= 0 AND iv <= 5),           -- IV范围 0-500%
    CHECK (delta >= -1 AND delta <= 1)     -- Delta范围 -1到1
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| position_id | UUID | ✅ | 关联的持仓ID |
| iv | DECIMAL(6,4) | ✅ | 隐含波动率 |
| delta | DECIMAL(6,4) | ✅ | Delta值 |
| recorded_at | TIMESTAMPTZ | ✅ | 记录时间（自动） |

**记录频率**: 每2小时记录一次（仅活跃持仓）

**示例数据**:
```sql
-- 2026-02-04 10:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1778, 0.3999);

-- 2026-02-04 12:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1825, 0.4123);

-- 2026-02-04 14:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1756, 0.3876);
```

**自动清理**: 当持仓关闭时，相关历史记录自动删除（CASCADE）

### 关系说明

**positions ↔ transactions (1:N)**
- 一个持仓可以有多笔交易
- 删除持仓时，自动删除所有相关交易（CASCADE）
- 通过`position_id`关联

**positions ↔ greeks_history (1:N)**
- 一个持仓可以有多条Greeks历史记录
- 删除持仓时，自动删除所有历史记录（CASCADE）
- 通过`position_id`关联

## 🚀 索引策略

### 主键索引（自动创建）

```sql
-- positions表
CREATE UNIQUE INDEX positions_pkey ON positions(id);

-- transactions表
CREATE UNIQUE INDEX transactions_pkey ON transactions(id);

-- greeks_history表
CREATE UNIQUE INDEX greeks_history_pkey ON greeks_history(id);
```

### 外键索引（自动创建）

```sql
-- transactions表
CREATE INDEX idx_transactions_position_id ON transactions(position_id);

-- greeks_history表
CREATE INDEX idx_greeks_history_position_id ON greeks_history(position_id);
```

### 业务索引（手动创建）

```sql
-- 按状态查询（最常用）
CREATE INDEX idx_positions_status ON positions(status);

-- 按到期日查询（警告系统）
CREATE INDEX idx_positions_expiration ON positions(expiration);

-- 按创建时间排序
CREATE INDEX idx_positions_created_at ON positions(created_at DESC);

-- 按交易时间排序
CREATE INDEX idx_transactions_date ON transactions(date DESC);

-- 按记录时间查询Greeks历史
CREATE INDEX idx_greeks_history_recorded_at ON greeks_history(recorded_at DESC);
```

### 复合索引（优化特定查询）

```sql
-- 查询特定状态的持仓并按创建时间排序
CREATE INDEX idx_positions_status_created ON positions(status, created_at DESC);

-- 查询特定持仓的交易记录并按时间排序
CREATE INDEX idx_transactions_position_date ON transactions(position_id, date DESC);
```

**启用RLS**:
```sql
ALTER TABLE positions ENABLE ROW LEVEL SECURITY;
ALTER TABLE transactions ENABLE ROW LEVEL SECURITY;
ALTER TABLE greeks_history ENABLE ROW LEVEL SECURITY;
```

CREATE POLICY "Allow all on positions"

FOR ALL

### 生产环境策略（未来）

**用户隔离**:
```sql
-- 添加user_id列
ALTER TABLE positions ADD COLUMN user_id UUID REFERENCES auth.users(id);

-- 只能访问自己的数据
CREATE POLICY "Users can only access their own positions"
ON positions
FOR ALL
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);

-- transactions和greeks_history通过JOIN继承权限
CREATE POLICY "Users can only access their own transactions"
ON transactions
FOR ALL
USING (
  EXISTS (
    SELECT 1 FROM positions 
    WHERE positions.id = transactions.position_id 
    AND positions.user_id = auth.uid()
  )
);
```

### Migration 003: IV Rank 历史表 (ticker_iv_snapshots)

**日期**: 2026-02-08

**用途**: 按标的存储每日 ATM IV 快照，用于计算 IV Rank / IV Percentile，供 Scanner 与 Strategy Recommender 评分使用。

**Schema**:
```sql
CREATE TABLE ticker_iv_snapshots (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    ticker VARCHAR(20) NOT NULL,
    recorded_date DATE NOT NULL,
    iv30 DECIMAL(8,6) NOT NULL,
    iv90 DECIMAL(8,6),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(ticker, recorded_date)
);

CREATE INDEX idx_ticker_iv_snapshots_ticker_date ON ticker_iv_snapshots(ticker, recorded_date DESC);

ALTER TABLE ticker_iv_snapshots ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all on ticker_iv_snapshots" ON ticker_iv_snapshots FOR ALL USING (true) WITH CHECK (true);
```

**说明**:
- 每次 Scanner 或 Strategy Recommender 请求会 upsert 当日 (ticker, recorded_date) 的 iv30/iv90。
- **服务端写入**：`lib/_shared/ivHistory.cjs` 的 `saveTickerIVSnapshot` 使用 **Supabase Secret Key**（`SUPABASE_SERVICE_ROLE_KEY`）写入，以绕过 RLS；仅配置 anon key 会报 401/RLS。见 [08_IV_Rank_上线步骤.md](./08_IV_Rank_上线步骤.md)。
- **历史回填**：初期曾使用 Polygon 历史 K 线计算 RV30 作为 IV30 代理数据进行回填（已完成，`source='rv_proxy'`）。回填脚本已退役。
- IV Rank = (当前 iv30 - 252 日内最小) / (252 日内最大 - 最小)；IV Percentile = 过去 252 日内 iv30 低于当前值的比例。
- 无历史数据时评分不包含 IV Rank 调整；数据随使用逐步积累。
- **Strategy Recommender** 在 Single-leg (LOQ)、Credit Spread、Debit Spread 三类策略中均通过 `getIVRankAdjustment(ivRank, strategy)` 参与评分（买方高 IV Rank 略降分、低略加分，卖方高 IV Rank 略加分、低略减分）。

### Migration 005: 全局应用设置（app_settings）

**日期**: 2026-02-14

**用途**: 持久化应用级配置（账户大小、风险比例、Tech Score 权重与周期），替代前端硬编码默认值。单行 Singleton 模式。

**SQL**:
```sql
CREATE TABLE IF NOT EXISTS app_settings (
  id         INTEGER PRIMARY KEY DEFAULT 1,
  settings   JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX IF NOT EXISTS app_settings_singleton ON app_settings ((true));

INSERT INTO app_settings (id, settings)
VALUES (1, '{
  "portfolio": { "accountSize": 5700, "riskPct": 1, "stopOutPct": 50 },
  "techScore": {
    "weights": { "w_mb": 30, "w_bxs": 30, "w_bxl": 15, "w_ema": 15, "w_mom": 10 },
    "periods":  { "sc_mb_len": 20, "sc_mb_smoothing": 7, "sc_osc_len": 7,
                  "sc_bx_s1": 5, "sc_bx_s2": 20, "sc_bx_s3": 5, "sc_bx_l1": 20, "sc_bx_l2": 5 }
  }
}'::jsonb)
ON CONFLICT (id) DO NOTHING;
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|

### Migration 009: IV 快照来源标记（source 字段）

**日期**: 2026-03-03

**用途**: 区分 `ticker_iv_snapshots` 表中的实时 IV 数据与历史 RV 代理回填数据。Forensic Audit v1.1 发现 RV < IV（波动率风险溢价），导致 IV Rank 使用 RV 代理行时系统性虚高至 ~100%。

**SQL**:
```sql
-- 添加 source 列，新行默认 'live_iv'
ALTER TABLE ticker_iv_snapshots
    ADD COLUMN IF NOT EXISTS source TEXT DEFAULT 'live_iv';

-- 将历史回填行（iv90 为 NULL）标记为 rv_proxy
UPDATE ticker_iv_snapshots
    SET source = 'rv_proxy'
    WHERE iv90 IS NULL AND source IS DISTINCT FROM 'rv_proxy';

CREATE INDEX IF NOT EXISTS idx_ticker_iv_snapshots_source
    ON ticker_iv_snapshots (ticker, recorded_date DESC, source);
```

**说明**: `getIVRank()` 现在仅使用 `source='live_iv'` 行计算排名，RV 代理行仅作为置信度不足时的补充（按 `RV_TO_IV_SCALE=1.15` 缩放）。

## 🔧 常用查询

### 查询所有活跃持仓及其交易记录

```sql
SELECT 
    p.*,
    json_agg(
        json_build_object(
            'id', t.id,
            'type', t.type,
            'quantity', t.quantity,
            'price', t.price,
            'date', t.date,
            'note', t.note
        ) ORDER BY t.date DESC
    ) AS transactions
FROM positions p
LEFT JOIN transactions t ON p.id = t.position_id
WHERE p.status = 'active'
GROUP BY p.id
ORDER BY p.created_at DESC;
```

### 计算持仓的P&L

```sql
WITH position_stats AS (
    SELECT 
        position_id,
        SUM(CASE WHEN quantity > 0 THEN quantity * price ELSE 0 END) / 
        NULLIF(SUM(CASE WHEN quantity > 0 THEN quantity ELSE 0 END), 0) AS avg_cost,
        SUM(quantity) AS current_quantity
    FROM transactions
    GROUP BY position_id
)
SELECT 
    p.ticker,
    p.strike,
    p.type,
    p.current_price,
    ps.avg_cost,
    ps.current_quantity,
    (p.current_price - ps.avg_cost) * ps.current_quantity * 100 AS unrealized_pnl
FROM positions p
JOIN position_stats ps ON p.id = ps.position_id
WHERE p.status = 'active';
```

### 查询Greeks历史（最近7天）

```sql
SELECT 
    position_id,
    iv,
    delta,
    recorded_at
FROM greeks_history
WHERE position_id = 'uuid-123'
  AND recorded_at >= NOW() - INTERVAL '7 days'
ORDER BY recorded_at ASC;
```

### 统计交易绩效

```sql
SELECT 
    COUNT(*) AS total_trades,
    COUNT(CASE WHEN status = 'closed' THEN 1 END) AS closed_trades,
    AVG(EXTRACT(EPOCH FROM (closed_at - created_at)) / 86400) AS avg_hold_days
FROM positions
WHERE status = 'closed';
```

## 📎 附录：完整 SQL Schema（重建用）

如需从零重建 `positions` 与 `transactions`，可在 Supabase SQL Editor 中执行：

```sql
-- 删除旧表（如存在）
DROP TABLE IF EXISTS transactions;
DROP TABLE IF EXISTS positions;

-- 创建 positions 表
CREATE TABLE positions (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    ticker VARCHAR(20) NOT NULL,
    strike DECIMAL(10,2) NOT NULL,
    type VARCHAR(50) NOT NULL,
    expiration DATE NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'watchlist' CHECK (status IN ('watchlist', 'active', 'closed')),
    setup VARCHAR(50),
    entry_score INTEGER,
    current_score INTEGER,
    score_updated_at TIMESTAMPTZ,
    ideal_entry DECIMAL(10,2),
    current_price DECIMAL(10,2),
    stop_reason TEXT,
    target_price DECIMAL(10,2),
    stop_price DECIMAL(10,2),
    legs JSONB,
    owner VARCHAR(20) DEFAULT NULL,
    strategy VARCHAR(50),
    exit_type VARCHAR(20),
    tech_score INTEGER,
    tech_score_source VARCHAR(20),
    market_state VARCHAR(20),
    trade_profile VARCHAR(20),
    iv_rank_entry DECIMAL(5,2),
    iv_regime_entry VARCHAR(20),
    notes TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    closed_at TIMESTAMPTZ
);

-- 创建 transactions 表
CREATE TABLE transactions (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    position_id UUID REFERENCES positions(id) ON DELETE CASCADE,
    type VARCHAR(20) NOT NULL CHECK (type IN ('Open', 'Size Up', 'Size Down', 'Take Profit', 'Close')),
    quantity INTEGER NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    date TIMESTAMPTZ DEFAULT NOW(),
    note TEXT
);

ALTER TABLE positions ENABLE ROW LEVEL SECURITY;
ALTER TABLE transactions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow all on positions" ON positions FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow all on transactions" ON transactions FOR ALL USING (true) WITH CHECK (true);

CREATE INDEX idx_positions_status ON positions(status);
CREATE INDEX idx_transactions_position_id ON transactions(position_id);
```
