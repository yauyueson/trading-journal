## 📊 表结构设计

### 1. positions (持仓表)

**用途**: 存储所有期权持仓（观察列表、活跃持仓、历史持仓）

**Schema**:
```sql
CREATE TABLE positions (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 期权基本信息
    ticker VARCHAR(20) NOT NULL,           -- 股票代码 e.g. "QQQ"
    strike DECIMAL(10,2) NOT NULL,         -- 行权价 e.g. 630.00
    type VARCHAR(10) NOT NULL,             -- "Call" 或 "Put"
    expiration DATE NOT NULL,              -- 到期日 e.g. 2026-02-20
    
    -- 状态管理
    status VARCHAR(20) NOT NULL DEFAULT 'watchlist',  
        -- 'watchlist': 观察列表
        -- 'active': 活跃持仓
        -- 'closed': 已平仓
    
    -- 交易计划
    setup VARCHAR(50),                     -- 交易设置类型 e.g. "MB Bounce"
    entry_score INTEGER,                   -- 入场时Scanner Score (0-100)
    current_score INTEGER,                 -- 当前Scanner Score (0-100)
    score_updated_at TIMESTAMPTZ,          -- Score最后更新时间
    ideal_entry DECIMAL(10,2),             -- 理想入场价 e.g. 7.50
    
    -- 价格和风控
    current_price DECIMAL(10,2),           -- 当前期权价格
    stop_reason TEXT,                      -- 技术止损条件 e.g. "MB flips red"
    target_price DECIMAL(10,2),            -- 目标价 e.g. 12.00
    
    -- 备注和时间戳
    notes TEXT,                            -- 交易笔记
    created_at TIMESTAMPTZ DEFAULT NOW(),  -- 创建时间
    closed_at TIMESTAMPTZ,                 -- 平仓时间
    
    -- 约束
    CHECK (type IN ('Call', 'Put')),
    CHECK (status IN ('watchlist', 'active', 'closed')),
    CHECK (strike > 0),
    CHECK (entry_score IS NULL OR (entry_score >= 0 AND entry_score <= 100)),
    CHECK (current_score IS NULL OR (current_score >= 0 AND current_score <= 100))
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| ticker | VARCHAR(20) | ✅ | 股票代码，大写 |
| strike | DECIMAL(10,2) | ✅ | 行权价，精确到分 |
| type | VARCHAR(10) | ✅ | Call或Put |
| expiration | DATE | ✅ | 到期日 |
| status | VARCHAR(20) | ✅ | 持仓状态 |
| setup | VARCHAR(50) | ❌ | 交易设置类型 |
| entry_score | INTEGER | ❌ | 入场评分 |
| current_score | INTEGER | ❌ | 当前评分 |
| score_updated_at | TIMESTAMPTZ | ❌ | 评分更新时间 |
| ideal_entry | DECIMAL(10,2) | ❌ | 理想入场价 |
| current_price | DECIMAL(10,2) | ❌ | 当前价格 |
| stop_reason | TEXT | ❌ | 止损条件 |
| target_price | DECIMAL(10,2) | ❌ | 目标价 |
| notes | TEXT | ❌ | 备注 |
| created_at | TIMESTAMPTZ | ✅ | 创建时间（自动） |
| closed_at | TIMESTAMPTZ | ❌ | 平仓时间 |

**示例数据**:
```sql
INSERT INTO positions (ticker, strike, type, expiration, status, setup, entry_score, ideal_entry, stop_reason)
VALUES 
  ('QQQ', 630.00, 'Call', '2026-02-20', 'watchlist', 'MB Bounce', 85, 7.50, 'MB flips red'),
  ('SPY', 580.00, 'Put', '2026-03-15', 'active', 'Breakdown', 72, 5.20, 'Breaks above 585');
```

### 2. transactions (交易记录表)

**用途**: 记录所有买入/卖出操作

**Schema**:
```sql
CREATE TABLE transactions (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 外键关联
    position_id UUID REFERENCES positions(id) ON DELETE CASCADE,
    
    -- 交易信息
    type VARCHAR(20) NOT NULL,             -- 交易类型
        -- 'Open': 开仓
        -- 'Size Up': 加仓
        -- 'Size Down': 减仓
        -- 'Take Profit': 部分止盈
        -- 'Close': 平仓
    
    quantity INTEGER NOT NULL,             -- 数量（正=买入，负=卖出）
    price DECIMAL(10,2) NOT NULL,          -- 成交价
    date TIMESTAMPTZ DEFAULT NOW(),        -- 交易时间
    note TEXT,                             -- 交易备注
    
    -- 约束
    CHECK (type IN ('Open', 'Size Up', 'Size Down', 'Take Profit', 'Close')),
    CHECK (quantity != 0),
    CHECK (price > 0)
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| position_id | UUID | ✅ | 关联的持仓ID |
| type | VARCHAR(20) | ✅ | 交易类型 |
| quantity | INTEGER | ✅ | 合约数量 |
| price | DECIMAL(10,2) | ✅ | 成交价格 |
| date | TIMESTAMPTZ | ✅ | 交易时间（自动） |
| note | TEXT | ❌ | 交易备注 |

**数量规则**:
- **正数**: 买入操作
  - `Open`: +5 (开仓5份)
  - `Size Up`: +3 (加仓3份)
- **负数**: 卖出操作
  - `Size Down`: -2 (减仓2份)
  - `Take Profit`: -3 (止盈3份)
  - `Close`: -5 (平仓5份)

**示例数据**:
```sql
-- 开仓5份 @ $7.50
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Open', 5, 7.50, 'Entry at ideal price');

-- 加仓3份 @ $6.80
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Size Up', 3, 6.80, 'Dip buy');

-- 止盈4份 @ $10.20
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Take Profit', -4, 10.20, 'Hit target');

-- 平仓剩余4份 @ $9.50
INSERT INTO transactions (position_id, type, quantity, price, note)
VALUES ('uuid-123', 'Close', -4, 9.50, 'Close remaining');
```

### 3. position_greeks_history (Greeks历史表)

**用途**: 存储IV和Delta的历史快照，用于图表展示

**Schema**:
```sql
CREATE TABLE position_greeks_history (
    -- 主键
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    
    -- 外键关联
    position_id UUID REFERENCES positions(id) ON DELETE CASCADE,
    
    -- Greeks数据
    iv DECIMAL(6,4) NOT NULL,              -- 隐含波动率 e.g. 0.1778
    delta DECIMAL(6,4) NOT NULL,           -- Delta值 e.g. 0.3999
    
    -- 时间戳
    recorded_at TIMESTAMPTZ DEFAULT NOW(), -- 记录时间
    
    -- 约束
    CHECK (iv >= 0 AND iv <= 5),           -- IV范围 0-500%
    CHECK (delta >= -1 AND delta <= 1)     -- Delta范围 -1到1
);
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键，自动生成 |
| position_id | UUID | ✅ | 关联的持仓ID |
| iv | DECIMAL(6,4) | ✅ | 隐含波动率 |
| delta | DECIMAL(6,4) | ✅ | Delta值 |
| recorded_at | TIMESTAMPTZ | ✅ | 记录时间（自动） |

**记录频率**: 每2小时记录一次（仅活跃持仓）

**示例数据**:
```sql
-- 2026-02-04 10:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1778, 0.3999);

-- 2026-02-04 12:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1825, 0.4123);

-- 2026-02-04 14:00
INSERT INTO greeks_history (position_id, iv, delta)
VALUES ('uuid-123', 0.1756, 0.3876);
```

**自动清理**: 当持仓关闭时，相关历史记录自动删除（CASCADE）

```
└─────────────────────┘

           │ 1
           │

┌──────────┴──────────┐
```

### 关系说明

**positions ↔ transactions (1:N)**
- 一个持仓可以有多笔交易
- 删除持仓时，自动删除所有相关交易（CASCADE）
- 通过`position_id`关联

**positions ↔ greeks_history (1:N)**
- 一个持仓可以有多条Greeks历史记录
- 删除持仓时，自动删除所有历史记录（CASCADE）
- 通过`position_id`关联

## 🚀 索引策略

### 主键索引（自动创建）

```sql
-- positions表
CREATE UNIQUE INDEX positions_pkey ON positions(id);

-- transactions表
CREATE UNIQUE INDEX transactions_pkey ON transactions(id);

-- greeks_history表
CREATE UNIQUE INDEX greeks_history_pkey ON greeks_history(id);
```

### 外键索引（自动创建）

```sql
-- transactions表
CREATE INDEX idx_transactions_position_id ON transactions(position_id);

-- greeks_history表
CREATE INDEX idx_greeks_history_position_id ON greeks_history(position_id);
```

### 业务索引（手动创建）

```sql
-- 按状态查询（最常用）
CREATE INDEX idx_positions_status ON positions(status);

-- 按到期日查询（警告系统）
CREATE INDEX idx_positions_expiration ON positions(expiration);

-- 按创建时间排序
CREATE INDEX idx_positions_created_at ON positions(created_at DESC);

-- 按交易时间排序
CREATE INDEX idx_transactions_date ON transactions(date DESC);

-- 按记录时间查询Greeks历史
CREATE INDEX idx_greeks_history_recorded_at ON greeks_history(recorded_at DESC);
```

### 复合索引（优化特定查询）

```sql
-- 查询特定状态的持仓并按创建时间排序
CREATE INDEX idx_positions_status_created ON positions(status, created_at DESC);

-- 查询特定持仓的交易记录并按时间排序
CREATE INDEX idx_transactions_position_date ON transactions(position_id, date DESC);
```


### 生产环境策略（未来）

**用户隔离**:
```sql
-- 添加user_id列
ALTER TABLE positions ADD COLUMN user_id UUID REFERENCES auth.users(id);

-- 只能访问自己的数据
CREATE POLICY "Users can only access their own positions"
ON positions
FOR ALL
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);

ON transactions
FOR ALL
USING (
  EXISTS (
    SELECT 1 FROM positions 
    WHERE positions.id = transactions.position_id 
    AND positions.user_id = auth.uid()
  )
);
```

### Migration 003: IV Rank 历史表 (ticker_iv_snapshots)

**日期**: 2026-02-08

**用途**: 按标的存储每日 ATM IV 快照，用于计算 IV Rank / IV Percentile，供 Scanner 与 Strategy Recommender 评分使用。

**Schema**:
```sql
CREATE TABLE ticker_iv_snapshots (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    ticker VARCHAR(20) NOT NULL,
    recorded_date DATE NOT NULL,
    iv30 DECIMAL(8,6) NOT NULL,
    iv90 DECIMAL(8,6),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(ticker, recorded_date)
);

CREATE INDEX idx_ticker_iv_snapshots_ticker_date ON ticker_iv_snapshots(ticker, recorded_date DESC);

ALTER TABLE ticker_iv_snapshots ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all on ticker_iv_snapshots" ON ticker_iv_snapshots FOR ALL USING (true) WITH CHECK (true);
```

**说明**:
- 每次 Scanner 或 Strategy Recommender 请求会 upsert 当日 (ticker, recorded_date) 的 iv30/iv90。
- IV Rank = (当前 iv30 - 252 日内最小) / (252 日内最大 - 最小)；IV Percentile = 过去 252 日内 iv30 低于当前值的比例。
- 无历史数据时评分不包含 IV Rank 调整；数据随使用逐步积累。

## 🔧 常用查询

### 查询所有活跃持仓及其交易记录

```sql
SELECT 
    p.*,
    json_agg(
        json_build_object(
            'id', t.id,
            'type', t.type,
            'quantity', t.quantity,
            'price', t.price,
            'date', t.date,
            'note', t.note
        ) ORDER BY t.date DESC
    ) AS transactions
FROM positions p
LEFT JOIN transactions t ON p.id = t.position_id
WHERE p.status = 'active'
GROUP BY p.id
ORDER BY p.created_at DESC;
```

### 计算持仓的P&L

```sql
WITH position_stats AS (
    SELECT 
        position_id,
        SUM(CASE WHEN quantity > 0 THEN quantity * price ELSE 0 END) / 
        NULLIF(SUM(CASE WHEN quantity > 0 THEN quantity ELSE 0 END), 0) AS avg_cost,
        SUM(quantity) AS current_quantity
    FROM transactions
    GROUP BY position_id
)
SELECT 
    p.ticker,
    p.strike,
    p.type,
    p.current_price,
    ps.avg_cost,
    ps.current_quantity,
    (p.current_price - ps.avg_cost) * ps.current_quantity * 100 AS unrealized_pnl
FROM positions p
JOIN position_stats ps ON p.id = ps.position_id
WHERE p.status = 'active';
```

### 查询Greeks历史（最近7天）

```sql
SELECT 
    position_id,
    iv,
    delta,
    recorded_at
FROM greeks_history
WHERE position_id = 'uuid-123'
  AND recorded_at >= NOW() - INTERVAL '7 days'
ORDER BY recorded_at ASC;
```

### 统计交易绩效

```sql
SELECT 
    COUNT(*) AS total_trades,
    COUNT(CASE WHEN status = 'closed' THEN 1 END) AS closed_trades,
    AVG(EXTRACT(EPOCH FROM (closed_at - created_at)) / 86400) AS avg_hold_days
FROM positions
WHERE status = 'closed';
```

## 🗑️ 数据清理

### 删除旧的Greeks历史（保留30天）

```sql
DELETE FROM greeks_history
WHERE recorded_at < NOW() - INTERVAL '30 days';
```

### 归档已平仓持仓（超过90天）

```sql
-- 创建归档表
CREATE TABLE positions_archive (LIKE positions INCLUDING ALL);

-- 移动数据
INSERT INTO positions_archive
SELECT * FROM positions
WHERE status = 'closed' 
  AND closed_at < NOW() - INTERVAL '90 days';

-- 删除原数据
DELETE FROM positions
WHERE status = 'closed' 
  AND closed_at < NOW() - INTERVAL '90 days';
```
